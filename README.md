# Student Management System (Java)

## Description
This is a **console-based Student Management System** built using **pure Java**.  
The system allows users to **add, display, search, and delete students**. All data is stored in memory using an ArrayList.

---

## Features
- Add a new student (ID, Name, Age, Grade)
- Display all students
- Search student by ID
- Delete student by ID
- Simple console-based interface
